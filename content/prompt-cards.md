# Prompt Cards — DAY 0

## Card 1 — Explain
อธิบาย [เรื่อง] สำหรับ [ระดับชั้น] ใน 5 ประโยค + ตัวอย่างใกล้ตัว 2 ตัวอย่าง + 3 จุดที่ควรตรวจสอบ

## Card 2 — Transform
เปลี่ยน [เนื้อหา] เป็นเกม Matching/Sorting/Quiz พร้อม Learning Goal, กติกา, คะแนน และ Feedback

## Card 3 — Visual
สร้าง Image Prompt สำหรับสื่อการสอนเรื่อง [เรื่อง] แบบ child-friendly ไม่มีข้อความในภาพ และระบุสิ่งที่ห้ามสร้าง

## Card 4 — Storyboard
สร้าง Storyboard 6 ฉาก: Hook → Problem → Learn → Decide → Solve → Lesson พร้อม Image Prompt และ Motion Prompt

## Card 5 — Code
สร้าง HTML/CSS/JavaScript ไฟล์เดียวสำหรับเกม [ชื่อ] ให้ครูแก้คำถามใน array ได้ง่าย รองรับมือถือ

## Card 6 — AR
สร้าง Camera AR Game: camera background + HTML overlay + tap target + score + feedback + 10 rounds

## Card 7 — Review
ตรวจผลงานใน 4 มุม: Accuracy, Age Appropriate, UX, Privacy แล้วจัด Fix เป็น P0/P1/P2

## Card 8 — Teach Back
สรุปวิธีทำผลงานนี้เป็นบทสอน 5 นาที: WHY → PROMPT → BUILD → TEST → SAFETY
