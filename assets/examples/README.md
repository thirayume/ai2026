# Workshop Example Assets

ไฟล์ทั้งหมดเป็น **Mock Data** สำหรับฝึกใน Workshop เท่านั้น ไม่มีข้อมูลส่วนบุคคลจริง

ใช้ path จากหน้าเว็บ:
`assets/examples/<filename>`

Assets สำคัญ:
- `lesson-food-chain.md` — เนื้อหาบทเรียนตัวอย่าง
- `mock-student-worksheet.png` — ภาพใบงานจำลอง
- `mock-student-scores.csv` — คะแนน Pre/Post จำลอง
- `mock-meeting-notes.md` — บันทึกประชุมจำลอง
- `mock-document-photo.png` — ภาพเอกสารจำลอง
- `mock-incident-notes.md` — Incident จำลอง
- `sample-ai-answer.md` — ข้อความที่จงใจมีข้อมูลผิดสำหรับ Fact Check
- `sample-phishing-email.md` — Email Phishing จำลอง
- `sample-buggy-game.js` — โค้ดมี Bug สำหรับ Debug/Review
- `ar-verb-words.json` — คำกริยา/คำหลอก
- `science-classification.json` — ชุดข้อมูล AR Classification
- `story-seed-phishing.md` — เนื้อเรื่องสำหรับ Storyboard
- `web-game-spec.md` — Game Spec ตัวอย่าง
