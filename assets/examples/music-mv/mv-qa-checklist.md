# Music + MV QA Checklist

## Song
- [ ] Original lyrics
- [ ] Original melody / hook
- [ ] No copied reference lyrics
- [ ] Thai diction understandable
- [ ] Chorus memorable
- [ ] Dynamics fit workshop use
- [ ] Exported master has no unwanted cut-off

## MV
- [ ] Audio is the final Suno master
- [ ] Character continuity maintained
- [ ] No accidental real-school logos
- [ ] No distorted Thai text used as critical information
- [ ] Visual cuts align with song energy
- [ ] No scene copies the reference MV shot-for-shot
- [ ] 16:9 master checked
- [ ] Mobile-safe crop checked if creating 9:16 derivative
- [ ] AI-generated video disclosure / platform requirements checked before publishing
