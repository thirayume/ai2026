# Reference Music DNA — Output Schema

The analysis tool should return:

1. Genre family
2. Subgenre / production era
3. Approximate tempo band
4. Meter / rhythmic feel
5. Energy curve
6. Main instrumentation
7. Drum character
8. Bass character
9. Harmonic density
10. Vocal format (solo/group/call-response)
11. Vocal texture (without identifying or cloning a singer)
12. Song structure
13. Hook design principle
14. Mix / space / ambience
15. Emotional arc
16. 8–12 safe style descriptors for Suno
17. Elements that must NOT be copied:
    - lyrics
    - melody
    - distinctive hook
    - signature vocal identity
    - uniquely recognizable arrangement
